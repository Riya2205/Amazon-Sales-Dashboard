Amazon Sales Analytics

An interactive Power BI dashboard built to analyze Amazon sales order data, providing a consolidated view of revenue performance, order fulfillment, and delivery patterns across India. The dashboard combines KPI cards, slicers, and multiple visualization types to surface sales trends and operational bottlenecks at a glance.

📊 Key Features
1. Sales KPI Card — Displays total sales amount (₹11,672K+), with a date-range slicer for custom time-period analysis
2. Courier Status Breakdown — Donut chart showing the distribution of orders across Shipped, On the Way, Cancelled, and Unshipped statuses
3. Top 5 Categories — Bar chart ranking the best-selling product categories by order count
4. Fulfillment Split — Compares orders fulfilled by Amazon vs. Merchant to assess fulfillment channel performance
5. Delivery Partner Performance — Visualizes order volume handled by delivery partners (e.g., Easy Ship)
6. Size-wise Order Distribution — Breaks down order counts across size variants (S, M, L, XL, XXL, XS)
7. State-wise Order Distribution — Ranks Indian states by order volume, highlighting key demand regions such as Maharashtra, Karnataka, and Telangana

🛠️ Tech Stack
1. Power BI — Dashboard design, DAX measures, and interactive visualizations
2. Power Query — Data cleaning, transformation, and shaping raw sales data into a report-ready format
   
🗂️ Data Source
Amazon sales order dataset, including order details, courier status, fulfillment type (Amazon/Merchant), product category, size, and ship-state information.

📈 Insights Delivered
1. Identified top-selling product categories to guide inventory and marketing priorities
2. Highlighted regional demand concentration to support logistics and delivery planning
3. Surfaced cancellation and unshipped order rates to flag potential fulfillment bottlenecks
4. Enabled flexible date-range filtering for period-over-period sales comparison

🚀 How to Use
1. Clone this repository
2. Open the .pbix file in Power BI Desktop
3. Use the date slicer and category filters to explore sales trends interactively

💼 Business Impact & Insights
1. Enabled data-driven inventory planning by highlighting which product categories drive the most orders
2. Supported smarter logistics decisions by identifying high-demand states for targeted delivery resource allocation
3. Helped reduce potential revenue loss by flagging high cancellation/unshipped rates for process improvement
4. Improved visibility into fulfillment channel efficiency (Amazon vs. Merchant), supporting better partner performance decisions
